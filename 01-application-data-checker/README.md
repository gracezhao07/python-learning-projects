# Application Data Checker

## About This Project

This is a simple Python command-line application that checks
whether student applications have all required information.

## Features

- Check multiple student applications.
- Identify missing required fields.
- Check whether an academic transcript has been uploaded.
- Display the application status.
- Show missing information for incomplete applications.

## Technologies

- Python 3
- VS Code

## How to Run

1. Open the project folder in VS Code.
2. Open the Terminal.
3. Run the following command:

   python3 main.py

## Example Output

Application: APP001
Status: Incomplete
Missing: ['email']

Application: APP002
Status: Ready to submit

Application: APP003
Status: Incomplete
Missing: ['academic transcript']

## Project Scope

This project checks application completeness only.
It does not assess academic eligibility or admission requirements.

The application data is fictional and stored directly in the Python code.
